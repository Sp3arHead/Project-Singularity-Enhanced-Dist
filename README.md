# Project Singularity — Enhanced edition
standalone admin panel for **FiveM for GTA V Enhanced** (`cfx-server`), replaces the bundled txAdmin, works with any framework.

Running FiveM (Legacy)? Use [Project-Singularity-Dist](https://github.com/Sp3arHead/Project-Singularity-Dist) instead.

## Install
1. Download `monitor.zip` from the [latest release](https://github.com/Sp3arHead/Project-Singularity-Enhanced-Dist/releases/latest).
2. Unzip it into `system_resources/txadmin` of your `cfx-server` folder, so `fxmanifest.lua` sits directly in `txadmin`.
3. Start `cfx-server` and open the panel on port 40120.

Later updates: *Master Actions → Panel setup → Panel Update*. They come from this repository only, so a Legacy build is never installed over Enhanced.

## Ports
panel 40120, game server 30120.

## What this repository contains
release downloads only. The source code is not public.
